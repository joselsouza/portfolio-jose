  1. AngraFight

    nov. de 2026Nov 2026

    Sistema de gestão para academia de Jiu-Jitsu Management system for a Jiu-Jitsu academy

    Desenvolvi de ponta a ponta o sistema que administra a academia AngraFight: cadastro de alunos, planos, mensalidades com cobrança automática via Asaas, controle de inadimplência e acompanhamento de graduação por frequência.     I built, end to end, the system that runs the AngraFight academy: student records, plans, monthly fees with automatic billing through Asaas, overdue tracking and belt promotion based on attendance. Attendance is recorded with in-browser face recognition running in a Web Worker; photos never leave the device, only numeric vectors reach the server. Students get their own portal and push notifications.

  3. Atlas: Agente RAGRAG Agent

    ago. de 2026Aug 2026

    Projeto final do curso “Agents For Everything” Final project for the “Agents For Everything” course

    Agente em Python que responde perguntas sobre o Oscar 2026 a partir de uma base de conhecimento local. O texto é dividido em trechos e transformado em embeddings com a API do Gemini; a pergunta do usuário passa pelo mesmo processo e o FAISS encontra os trechos mais próximos por similaridade. O Gemini então gera a resposta usando só esse contexto recuperado.

    A Python agent that answers questions about the 2026 Oscars from a local knowledge base. The text is split into chunks and turned into embeddings with the Gemini API; the user's question goes through the same step and FAISS finds the closest chunks by similarity. Gemini then writes the answer using only that retrieved context.
